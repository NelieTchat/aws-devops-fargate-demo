# AWS DevOps Fargate Demo (Dev-first)

Portfolio-ready project: containerized app deployed to AWS ECS Fargate, provisioned with Terraform, automated via GitHub Actions.

## Phases
1. Scaffold repo (you are here ✅)
2. Local app (Node.js) run
3. Dockerize app
4. Dev infra on AWS (Terraform, default VPC)
5. CI/CD with GitHub Actions
6. Hardening & extensions (VPC, Secrets Manager, monitoring)

> Built step-by-step for clarity and learning.
